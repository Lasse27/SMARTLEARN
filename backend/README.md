# backend

Ordner für die Backend-Anwendung, die mit FastAPI entwickelt werden soll


## Installation (Windows)

1. Konsole öffnen im Pfad `SMARTLEARN\backend`.

2. Virtuelle Python-Umgebung erstellen mit:

```ps1
python -m venv .venv   
```

3. `pip` aktualisieren mit:

```ps1
python.exe -m pip install --upgrade pip
```

3. Abhängigkeiten installieren mit:

```ps1
pip install -r .\requirements.txt
```


## Aktivieren der virtuellen Umgebung (Windows)

> Normalerweise machen die IDEs wie VSCode das automatisch, wenn nicht:

1. Konsole öffnen im Pfad `SMARTLEARN\backend`.

2. Virtuelle Umgebung aktivieren:

```
.\.venv\Scripts\activate.ps1
```
